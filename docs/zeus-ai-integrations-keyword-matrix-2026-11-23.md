## Проверка рекомендаций Алисы и Gemini

- Первоисточник конкретных рекомендаций и их дата должны быть сохранены с дословным текстом/ссылкой. До этого нельзя помечать рекомендацию «выполнена» или приписывать её определённому ИИ.
- Сверять каждую рекомендацию с фактическим HTML, robots.txt, sitemap, Google Search Console, Яндекс Вебмастером, GitHub Actions и живым REG.RU. Колонки учёта: источник, рекомендация, риск, решение, файл/коммит, проверка сервера, статус.
- Нельзя обещать, что структурированные данные или ключевые слова гарантируют попадание в AI Overview, ответы Алисы/Gemini либо топ поиска.

## Три сравнительных источника — без копирования

1. portal-yuridicheskih-uslug.ru — проверить навигацию по проблеме и прозрачность контактов; адаптировать только UX-принципы.
2. 9111.ru — проверить структуру вопросов и ответов; создавать собственные юридические разборы, не импортировать пользовательские персональные данные.
3. pravoved.ru — проверить понятность пути от проблемы к специалисту; не копировать отзывы, рейтинги, карточки юристов и тексты.

Это список гипотез для предметного аудита, а не подтверждение реализации чужих функций на сайте.

## Безопасная архитектура ИИ

- Сайт остаётся статическим на REG.RU; секретные API-ключи никогда не передавать в клиентский HTML/JS, GitHub, sitemap, публичные логи и issue.
- До активации API проверить наличие официальных договоров/ключей, региональную доступность, лимиты, тарификацию, допустимость обработки данных, согласие и применимые требования 152-ФЗ.
- Для Gemini и YandexGPT предусмотреть независимые серверные адаптеры с выключенным по умолчанию режимом, лимитом 0 ₽ до отдельного согласования, тайм-аутом, квотами, журналом без персональных данных, проверкой ошибок и возможностью отзыва ключа.
- Данные доверителей, переписку, материалы дел и контакты не направлять внешним моделям автоматически. Публичные юридические тексты могут проходить редакционную проверку ИИ, но факты и правовые выводы проверяет человек.
- Алиса как голосовой продукт, YandexGPT как API, Gemini как API и ChatGPT как ассистент — разные сервисы. Их «связь» не появляется от наличия общих ссылок на сайте.

## Критерии приёмки

1. У каждой рекомендации есть первоисточник и конкретный проверенный статус.
2. Изменения оформлены коммитом и проходят существующие тесты; рабочая выкладка подтверждается HTTP и содержимым, а не одним GitHub-коммитом.
3. Безопасность: скан отсутствия секретов, CSP/заголовки по возможности хостинга, согласие на аналитику, отсутствие передачи клиентских данных внешним ИИ.
4. Отдельный отчёт о Google/Яндексе; принятие sitemap не равно индексации.
5. Никаких платных API или изменений рекламного бюджета без отдельного согласия владельца.
